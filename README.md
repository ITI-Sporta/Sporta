# Sporta 🏆

## Project Overview
Sporta is an iOS application developed using Swift and UIKit.  
The app allows users to browse different sports leagues, view league details, upcoming events, latest results, live fixtures, and manage favorite leagues.

---

## Features
- Browse sports categories
- Paper Onbarding
- Lottie Animation
- View leagues for each sport
- League details screen
- Team details screen
- Upcoming events
- Latest results
- Live Fixtures
- Favorite leagues using Core Data
- Network connectivity check
- API integration using Alamofire

---

## Technologies Used
- Swift
- UIKit
- Core Data
- Alamofire
- Lottie-ios
- Paper Onboarding
- MVP Architecture
